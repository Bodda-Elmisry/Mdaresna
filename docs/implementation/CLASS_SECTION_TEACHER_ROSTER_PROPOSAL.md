# خطة فريق مدرسي الفصل

الحالة: منفذ في Schools API وSchools Web وSchools Flutter — 2026-09-23.

## نتيجة التنفيذ

- أضيف `ClassSectionTeacherScope` مع soft delete والتدقيق وconcurrency.
- أضيف Action «مدرسو الفصل» على سطر الفصل؛ تختار المادة ثم عدة مدرسين مؤهلين لها، وتحتفظ النافذة باختيارات كل المواد حتى الحفظ الذري.
- خيارات الأساسي والبديل في جدول الفصل أصبحت مقصورة على المدرسين المختارين للمادة داخل الفصل، مع دعم الإسنادات القديمة أثناء الترقية.
- تمنع الـAPI إزالة مدرس مستخدم حاليًا في جدول الفصل، وتمنع تعطيله قبل إزالته من الفصول والجداول.
- تعرض تفاصيل المدرس المواد والفصول المختار لها، منفصلة عن الإسناد الفعلي كأساسي أو بديل.
- migrations: PostgreSQL `20260923194432_AddClassSectionTeacherScopes` وSQL Server `20260923194446_AddClassSectionTeacherScopes`، وتشملان backfill لإسنادات الجداول القائمة.

## الهدف

إضافة Action «مدرسو الفصل» على سجل الفصل مثل `Grade 1A`. يفتح نافذة تبدأ باختيار مادة من مواد الصف المشغلة، ثم تعرض multi-select بالمدرسين الذين لديهم نطاق تدريس فعال لنفس المادة والصف والعام، لاختيار مدرسي هذه المادة داخل الفصل.

## الفصل بين مستويات الإسناد

1. `TeacherGradeSubjectScope`: المدرس مؤهل لتدريس مادة محددة في صف وعام محددين.
2. `ClassSectionTeacherScope`: المدرس مختار ضمن فريق فصل محدد لمادة محددة، دون اعتباره أساسيًا أو بديلًا بعد.
3. `ClassSubjectTeacherAssignment`: المدرس أساسي أو بديل لمادة فعلية داخل الفصل.
4. `WeeklyTimetableSlot`: موعد الحصة الأسبوعية الفعلي.

## نموذج البيانات

كيان جديد `ClassSectionTeacherScope`:

- `Id`
- `ClassSectionId`
- `TeacherGradeSubjectScopeId`
- `IsActive`
- حقول soft delete والتدقيق و`RowVersion`
- unique index فعال على `(ClassSectionId, TeacherGradeSubjectScopeId)`

لا يُضاف دور المادة أو دور «أساسي/بديل» إلى هذا الكيان؛ هذه المسؤولية تظل في `ClassSubjectTeacherAssignment`. وإذا احتاج النظام لاحقًا «رائد فصل» أو «مشرف فصل» فتُضاف مسؤولية مستقلة حتى لا تختلط بعضوية فريق التدريس.

## قواعد العمل

- المرشح يجب أن يكون `Teacher` وغير موقف أو معلق.
- تعرض قائمة المواد فقط `GradeSubjectOffering` التابعة لنفس `GradeOffering` الخاص بالفصل.
- بعد اختيار المادة، تعرض النافذة فقط المدرسين الذين يمتلكون `TeacherGradeSubjectScope` فعالًا لنفس مادة الصف.
- يمكن اختيار أكثر من مدرس للمادة الواحدة داخل الفصل، ويمكن اختيار المدرس نفسه لأكثر من مادة إذا كان نطاقه يسمح بذلك.
- لا يمكن إضافة مدرس من صف أو عام مختلفين.
- لا يمكن إزالة مدرس من فريق الفصل إذا كان مسندًا حاليًا كأساسي أو بديل لمادة داخل الفصل؛ يجب إزالة إسناده من الجدول أولًا.
- خيارات المدرس داخل جدول حصص الفصل تُرشح بعد التنفيذ بشرطين معًا: نطاق المادة الصحيح + اختياره لهذه المادة داخل الفصل.
- تغيير عضوية الفصل لا يغير نطاق المدرس الأصلي ولا يحذف سجلات الجدول تلقائيًا.

## الـAPI

- `GET /api/schools/v1/teaching-planning/class-sections/{classSectionId}/teacher-options`
  - يعيد بيانات الفصل ومواد الصف، ولكل مادة المدرسين المؤهلين وحالة اختيارهم.
- `PUT /api/schools/v1/teaching-planning/class-sections/{classSectionId}/teacher-scopes`
  - يستقبل قائمة المواد ومع كل مادة `teacherGradeSubjectScopeIds`، ويتحقق منها ويحفظ كل اختيارات النافذة في transaction واحدة.

- التعديل: `school.academics.manage`

## تجربة الواجهة

- Action «مدرسو الفصل» داخل سطر الفصل في تبويب الفصول الدراسية.
- نافذة بسيطة تعرض اسم الفصل، الصف، نوع التعليم والعام الدراسي.
- ComboBox لاختيار مادة الصف، ثم بحث بالاسم وعدد المختارين وقائمة checkboxes متعددة الاختيار.
- كل سطر يعرض الصورة واسم المدرس واسم الدخول؛ تغيير المادة لا يفقد اختيارات المواد الأخرى، وزر حفظ واحد يحفظ النافذة كاملة بصورة ذرية.
- زر حفظ واحد ورسالة واضحة عند محاولة إزالة مدرس مستخدم في الجدول.
