# سجل تطوير مشروع مدارسنا

هذا المجلد هو المصدر المختصر لسياق المشروع بين جلسات التطوير، والهدف منه تقليل إعادة فحص المشروع واستهلاك الوقت والـtokens.

## ترتيب القراءة

1. `CURRENT_STATE.md`: الحالة الحالية الفعلية للنظام.
2. `DECISIONS.md`: القرارات المعمارية الثابتة وأسبابها.
3. آخر إدخالات `DEVELOPMENT_LOG.md`: آخر نقاشات وتعديلات تمت.
4. `NEXT_STEPS.md`: الأعمال المتبقية أو المؤجلة.

## قواعد التحديث

- يضاف سجل جديد بعد كل تعديل مهم أو نقاش ينتج عنه قرار.
- السجل مختصر ويركز على النتيجة، الملفات المتأثرة، والتحقق المنفذ.
- لا تُسجل الأسرار أو قيم connection strings أو مفاتيح التشفير.
- عند اختلاف التوثيق عن الكود، يُراجع الجزء المختلف فقط ثم يُصحح التوثيق.
- لا يُعاد وصف تاريخ قديم كاملًا في كل إدخال؛ يُستخدم رابط أو مرجع للقرار ذي الصلة.

## صيغة إدخال السجل

```md
## YYYY-MM-DD — عنوان مختصر

- النوع: نقاش | قرار | ميزة | إصلاح | إعداد | نشر
- النطاق: Backend | Platform Web | Platform Flutter | Schools Web | Schools Flutter
- النتيجة: ما الذي أصبح يعمل الآن؟
- أهم الملفات: المسارات الرئيسية فقط.
- التحقق: أوامر الاختبار أو البناء ونتيجتها.
- متابعة: الخطوة التالية إن وجدت.
```
