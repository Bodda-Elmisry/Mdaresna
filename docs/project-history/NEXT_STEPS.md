- اكتمل «تذكرني» وتجديد الجلسة في Platform وSchools على Web وFlutter: refresh token دوّار، استعادة عند التشغيل، تجديد استباقي، تخزين آمن للموبايل، فصل تخزين الويب الدائم عن جلسة التبويب، وإبطال الجلسة عند الخروج دون migration جديدة.
- اكتمل Student Core ودورة القبول الأولية في Backend وWeb وFlutter: كود عالمي مركزي، طالب محلي مع عدة أولياء وأحدهم أساسي، قيد مباشر، طلب يدوي من مقر المدرسة، فلاتر Server-side، وقبول الطلب وتحويله إلى طالب وقيد مع اختيار الفصل وفحص السعة.
- اكتملت دورة تغطية غياب المعلم في Backend وWeb وFlutter: الإسناد الفعلي المؤرخ، ظهوره في جدول البديل مع الفصل والمدرس الغائب، وإشعار داخلي عند التكليف أو الإلغاء مع عداد وحالات قراءة.
- اكتمل التسجيل اليدوي الأولي لغياب وإذن وإجازة المعلمين والموظفين من الشاشات التشغيلية، وتغطية حصص المعلم ببديل فعلي مؤرخ مع فحص تعارضه وغيابه، وتجهيز `SourceType/SourceReferenceId` لتكامل HR المستقبلي دون إعادة تصميم.
- اكتمل إبقاء إدارة المعلمين والموظفين داخل الإعدادات وإضافة شاشتين تشغيليتين مستقلتين بلا عمليات إدارة حساب، مع فلاتر القسم والاسم والهاتف وتطبيق نطاق القسم على القائمة والتفاصيل وجدول المعلم.
- اكتمل حجز الغرف داخل حصص الجدول الأسبوعي وعرض جدول الغرفة، مع مشاركة المعمل بين عدة فصول بقيود الموافقة والسعة، ودمج مؤقت مؤرخ لفصلين أو أكثر يعتمد الحضور المتوقع ولا يغير الجدول الأساسي.
